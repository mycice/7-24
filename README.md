# 四面体-网格耦合手术仿真原型

本项目旨在构建一个结合**四面体软体物理**与**规则网格切割**的手术仿真原型。

项目采用双表示方案：

- 四面体模型负责软体器官的物理模拟、碰撞和夹取；
- 规则背景网格负责器官切割、表面重建和视觉表现；
- 两种表示通过同步机制进行位置和形变关联。

项目主要参考并融合了以下两个方向：

- `SoftTissue-SurgicalSim-main`：四面体软体物理、碰撞与夹取；
- `recon-grid-dc`：规则网格切割与表面重建。

本项目目前处于科研与工程原型阶段，重点用于双表示耦合、CUDA 加速和手术交互流程的研究与验证。

## 整体技术路线

双表示耦合原型按照以下五个阶段逐步开发：

1. 建立四面体软体物理底座；
2. 移植并验证夹爪抓取功能；
3. 建立四面体物理模型与规则切割网格之间的同步机制；
4. 验证夹爪与 Haply 刀同时操作同一器官；
5. 实现真实物理切断以及切割后组织的独立运动。

阶段一、阶段二和阶段三已经完成，当前即将进入阶段四和阶段五。

## 开发阶段

### 阶段一：建立四面体软体物理底座

将显式四面体 XPBD 物理系统移植到目标项目中，使器官能够：

- 受到重力作用；
- 与地面发生碰撞；
- 在地面上稳定运动；
- 使用接近源项目的器官、材料、质量和阻尼参数。

本阶段暂不接入 CUDA 切割网格，重点是验证四面体器官物理系统能够独立运行。

### 阶段二：移植夹爪抓取功能

在四面体物理器官的基础上，移植碰撞与抓取机制，使夹爪能够：

- 检测器官表面接触；
- 抓取四面体器官；
- 在重力作用下稳定移动或悬挂器官；
- 与 Haply 等交互设备建立基础操作流程。

涉及的主要模块包括：

- `SoftTissueCollisionModule`
- `SoftTissueGrabbingModule`
- `GripperTool`

### 阶段三：建立双表示同步机制

阶段三的目标是让规则网格表示的器官跟随四面体物理模型运动和变形。

在这一阶段中，四面体模型负责物理计算，规则网格模型继续负责切割与表面重建。为了完成两种表示之间的耦合，阶段三依次解决了以下四个问题：

1. **模型同步**

   建立四面体模型与规则网格模型之间的位置和形变同步，使规则网格器官能够跟随四面体器官运动。

2. **切割算法**

   保证 Haply 刀具在器官移动和变形后仍能够正确进行切割，并保持切割空间、切割位置和切割结果的一致性。

3. **从 CPU 到 GPU 的迁移**

   将相关计算逐步迁移到 CUDA/GPU 环境，以满足实时手术仿真对计算性能的要求。

4. **优化高斯夹取**

   对高斯夹取相关功能进行优化，使夹爪能够更加稳定、准确地作用于器官模型，并适应双表示同步后的交互流程。

只有在以上四个问题全部解决后，阶段三才算完整完成。目前阶段三已经完成。

#### CUDA 迁移分支

仓库中的 `feature/cuda-gpu-resident-phase1` 分支用于表示和维护阶段三中“从 CPU 到 GPU 的迁移”相关代码。该分支记录 CUDA 迁移过程中的 GPU 计算、数据结构调整和性能优化工作。

### 阶段四：夹爪与 Haply 刀协同操作

阶段四将验证夹爪和 Haply 刀同时操作同一器官的完整交互流程：

- 夹爪夹住并搬移器官；
- Haply 刀对器官的其他区域进行切割；
- 规则网格切割结果正确响应器官的移动和形变；
- 夹爪动作不会导致刀具切割空间发生错位；
- 验证双表示系统中的坐标同步、交互时序和运行性能。

本阶段重点是完成双表示系统的协同操作验证，暂不要求切割结果立即修改四面体物理拓扑。

### 阶段五：实现真实物理切断

阶段五是项目的最终目标。切割事件不仅需要更新规则网格的视觉结果，还需要同步修改四面体物理模型的拓扑连接。

预期实现效果包括：

- 夹爪夹住器官的一侧；
- Haply 刀切割器官的另一侧；
- 切割后组织两侧失去物理连接；
- 被夹住的一侧继续受到夹爪约束；
- 另一侧能够在重力和接触条件下独立运动、下垂或掉落；
- 夹爪能够重新抓取切下来的组织块。

## 仓库结构与分支说明

### `main`

`main` 分支用于维护项目主线代码和双表示耦合原型的整体开发进度。

### `feature/cuda-gpu-resident-phase1`

`feature/cuda-gpu-resident-phase1` 分支专门用于维护阶段三中从 CPU 到 GPU 的 CUDA 迁移代码，与主线开发相互配合。

### 主要目录

- `SoftTissue-SurgicalSim-main`：四面体软体物理、碰撞和夹取相关项目；
- `recon-grid-dc`：规则网格切割、表面重建和 CUDA 相关代码。
