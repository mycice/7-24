**S1-I14** [high] theta_dot (Eq14 damping term, design line 188) is specified as the bare analytic d/dt acos(N_ij·N_ik) with no guard on its 1/sqrt(1-dot^2)=1/|sin θ| denominator. The 3 collinear bending pairs (+X/-X, +Y/-Y, +Z/-Z) sit at θ=π (dot=-1) at rest, so theta_dot → NaN/Inf on frame 0 for every particle, and is folded into s (line 189) BEFORE the only degeneracy guard (line 194). **S2-C4** [high] CONN4096 LUT outputs only compCount[config] + edgeToComp[config][12] (one component id per EDGE), but the paper's cut-feature-point algorithm is VERTEX-keyed: per connected component, iterate the component's vertices, then each vertex's 3 edges, accumulating the cut point bound to that vertex's endpoint into that vertex's component centroid. A per-edge slot cannot encode the two different endpoint-components of a severed edge, and is entirely undefined for an isolated vertex whose 3 incident edges are all cut (the all-edges-cut -> 8 singleton components case the design's §5.10/C48 test explicitly mandates). There is no vertToComp buffer anywhere in the design (§3 buffers, §5.4 output).
- FIX: Add vertToComp[config][8] (vertex -> component id from union-find on uncut-edge subgraph; isolated vertex = own component) as a primary ConnectivityLUT output; drive §5.5 centroid accumulation and feature-point-slot indexing from it (each cut edge adds its V_a-bound cut point to vertToComp[V_a] and its V_b-bound cut point to vertToComp[V_b]); keep edgeToComp only for uncut-edge stitching in §5.6.

**S2-C5** [high] θ̇ in the bending block (design §4.4 line 188) is computed as the unguarded analytic derivative d/dt acos(N_ij·N_ik) = -ċ/√(1-c²). For the 3 collinear opposite-axis bending pairs (c=N_ij·N_ik=-1 at rest, θ0=π), √(1-c²)=0; at rest ċ=0 too, so θ̇=0/0=NaN on the very first force evaluation. The only degenerate guard (C34) covers cross≈0 on the FORCE and is placed after the atomicAdd; it does not protect the θ̇ computation at line 188.
- FIX: At L188 guard the singularity: let d=√(1-c²); θ̇ = (d>eps) ? −ċ/d : 0 (bending damping vanishes smoothly at straight/folded configs), or equivalently compute the angular rate from perpendicular relative velocity with an explicit denom guard; document the eps-guard as PAPER-SILENT alongside C33.
